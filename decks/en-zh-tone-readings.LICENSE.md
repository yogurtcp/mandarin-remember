# Mandarin syllable-boundary data

The app's existing authored pinyin readings are retained unchanged. Syllable
boundaries were cross-checked using [CC-CEDICT](https://cc-cedict.org/wiki/),
the community-maintained Chinese-English dictionary distributed by MDBG.
No dictionary definitions are included in this boundary file.

The boundary annotations in `en-zh-tone-readings.json` are made available under
[Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/),
with attribution to the CC-CEDICT community for the reference data. The annotation
file is an adaptation for this app's stable card IDs, readings, and compact 儿 suffixes.
This data notice does not change the license of the application code.
